# Firstlight — Flagship phone showcase

A responsive, dependency-free static website comparing three 2026 flagship phones. All phone illustrations are drawn with CSS, so the site does not rely on remote product photos. Manufacturer links are included beside each phone; specs can vary by country and should be checked with the manufacturer before publishing.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy to Vercel

1. Put this folder in a Git repository and push it to GitHub, GitLab, or Bitbucket.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Set the project root to `flagship-showcase` if the folder is inside a larger repository.
4. Choose **Other** as the framework preset. Leave the build and output commands empty; the site is static.
5. Deploy.

You can also install the Vercel CLI and run `vercel` from this folder, then `vercel --prod` when you are ready to publish.
